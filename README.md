# OpenCLScope™ Database 3.4.4

Paired source-only companion for OpenCLScope Android 3.4.0/30400. Strictly accepts complete, live, explicitly submitted 3.4.0 producer reports, preserving verified 3.0.14 reports for historical reads only. Partial/unavailable/imported results never become complete records.

## Windows PowerShell deployment

```powershell
$zip = "$env:USERPROFILE\Downloads\OpenCLScope-Database-3.4.4.zip"
$repo = "C:\Users\Administrator\Desktop\OpenCLScope_database"
Expand-Archive -LiteralPath $zip -DestinationPath $repo -Force
Set-Location $repo
python -B tools\reconcile_repository.py --apply
python -B tools\reconcile_repository.py --check
python -B tools\verify_release.py
node tools/run_tests.mjs
cd worker
npm run deploy
cd ..
git add -A
git commit -m "Release OpenCLScope Database 3.4.4"
git push origin main
```

Deploy the Worker before installing the app producer when new uploads are needed. Cloudflare deployment, D1 writes, GitHub Actions and live Pages output have not been executed here. No new GPU properties or stored reports are generated by this release. The immutable VulkanScope reference CSS, controls, and official OpenCL schema are retained.

Database 3.4.4: Statistics extension frequency now supports complete 25/50/100-row pages with bounded reference-style page jump and correct loaded-report denominators.
