# OpenCLScope Database 1.0.0 — VulkanScope Database 1.4.12 visual reference

## Reference and delta
- Reference: immutable VulkanScope Database 1.4.12 full archive (`VulkanScope-Database-1.4.12(1).zip`); authoritative site stylesheet copied exactly to `assets/vulkan-layout.v1412.css`.
- OpenCLScope Database 0.12.60 is the predecessor. Replaced old hand-copied upstream CSS with the exact reference stylesheet loaded once, then one OpenCL-specific override stylesheet.
- Title/favicon: exact `OpenCLScope-1.0.19` application master artwork on solid black, derived into browser icon sizes. Header retains official OpenCLScope horizontal lockup, with black background like upstream.
- Same upstream icons for shared navigation and settings controls, icon-bearing section headings; responsive 320px/390px header scroll preserved.
- Reports: paginated semantic table with official vendor art, timestamps, driver, OpenCL version, report ID and actions; missing values represented as unreported, not supported.
- Statistics: reference-like summary cards and bars; only loaded complete technical reports contribute to histograms.
- Compare: semantic names, reference-like data grid, missing fields are UNKNOWN / not reported.
- Brand accent: green official OpenCL tone (#3DAE2B); neutral surfaces remain upstream charcoal; true query error uses red and unavailable neutral.
- API/Worker payload/schema, cache-first snapshot, report hashing, existing published report reading remain unchanged. New POST supports exact OpenCLScope 1.0.19/10019 only; reject earlier versions.

## Limits
- Vulkan-specific WSI, Turnip and physical-device fields are not portable to OpenCL. Neither names nor data may be fabricated.
- Browser pixel-level identity across non-equivalent reports is not guaranteed. Cloudflare production deployment requires user credentials.
