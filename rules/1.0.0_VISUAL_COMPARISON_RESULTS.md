# Database 1.0.0 visual comparison: VulkanScope Database 1.4.12

## Source evidence
- Verified against the user Library source archive `VulkanScope-Database-1.4.12(1).zip` (860 files including folders), not screenshot guesses.
- Original VulkanScope `assets/site.v1412.css` SHA-256 `bd5957461701439a7655c652b4e560cb84b7cc0163f202a257e019c2c468181b`; copied byte-for-byte as `assets/vulkan-layout.v1412.css`.
- OpenCLScope Database predecessor: 0.12.60. Current release: 1.0.0. Both share fonts, geometry, common component selectors and matched SVG icon paths where the semantic action is shared. A single OpenCL theme stylesheet follows the upstream CSS, without a second old reference stylesheet.
- Browser title favicon sourced from app OpenCLScope 1.0.19 `openclscope_logo_master.png`, maintaining black background and the actual CL/SCOPE logo.

## Implemented parity areas
- Header / responsive nav: VulkanScope nav button geometry, left/right scroll, exact common icon shapes, selected tab, dark black logo surface.
- Home / hero: title typography, repository/developer/evidence stack, status text and contrast, search and metrics panel hierarchy.
- Reports: paginated tabular layout, device/vendor icon, submitted timestamp, driver/API/platform columns, ID-copy and favorite actions, tablet/mobile horizontally scrolling table only, not entire page.
- Details: icon-bearing tabs, upstream typography and compact action grid with real OpenCL evidence.
- Statistics: summary metric cards and three proportional bar groups computed solely from loaded complete reports; no fabricated report counts.
- Compare: canonical semantic property comparison maintained, three-column baseline-target evidence grid, missing fields UNKNOWN.
- Settings: four tabs with aligned reference SVG icons, preferences, favorites, local clock and browser information.
- Color hierarchy: original black/gray surfaces and text; OpenCL green accent only for branding and available status; red error/unsupported, gray unknown/unavailable.

## Intentional non-equivalence and not-yet-verified
- Vulkan has 18 workspaces and 100 HTML IDs while OpenCL has 11 workspaces and 92 IDs. Vulkan-only Surface/WSI/Turnip/Display-HDR subviews cannot be copied as supported OpenCL features.
- Queries/worker schema remain OpenCL-specific (schema 1; 16 platform + 211 device queries). Only app version 1.0.19/10019 allowed for new POST submissions; historical report reads remain allowed.
- Source parity and browser responsive checks cannot prove exact pixel identity on all platforms/fonts, real Cloudflare deployment, or screenshots with production-sized report sets.
