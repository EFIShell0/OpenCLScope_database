# Database 1.0.1 — Reference chrome and scrolling parity

## Provenance
VulkanScope Database 1.4.12 reference `assets/site.v1412.css` is kept byte-identical in `assets/vulkan-layout.v1412.css`. OpenCLScope Database 1.0.0 is the immutable predecessor. The pinned application master supplies the title artwork. No report evidence, query manifest or collector values were synthesized.

## Changed
- Real original black-backed application master, 48px icon with an accessible OpenCLScope Database wordmark; previous improvisation removed from the header.
- Source-identical VulkanScope 1.4.12 table scroller function (keyboard, track, thumb drag, edge fades and chevrons) ported without altering its interaction geometry. Technical workspace reports now use the same table-scroll primitives instead of hardcoded card-only layouts.
- Consistent navigation classes, SVG sizes, edge fades, hover/active transitions, Settings and action surfaces, report row and statistical bar treatment.
- Full evidence details only display values already present in canonical report objects; successful empty OpenCL query values remain valid, and unreported statuses stay explicit.
- Preserve source-original OpenCL accent green, shared neutral state colors, privacy/snapshot-first behavior, Worker POST minimum 1.0.19 / 10019 and prior GET readability.

## Evidence limitations
HTML/CSS/JS source geometry is adapted from upstream and Chromium responsive tests may pass, but Vulkan-only views have no OpenCL equivalent. Full pixel equality, live Worker/D1/GitHub Pages and real-device acceptance are not proven by these source changes.
