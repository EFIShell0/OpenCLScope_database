## Rules kept unchanged

- Vulkan-only queues, WSI, Surface/HDR, Turnip, Vulkan registry/API semantics must not be inserted as OpenCL facts.
- Native OpenCL query output, registry lock, Worker report schema, historical producer allowlist, SHA report identity, API endpoints, bounded snapshot and cache-first loading remain authoritative.
- Favorites/settings remain **local to the browser**, never submitted with reports or stored in Cloudflare D1; they are persistent only by explicit user choice.
- Regional preferences change presentation and do not rewrite UTC source timestamps, ordering, comparisons or report hashes.
- Do not claim the GitHub Actions failure is identified from the scrolled screenshot. If the new release also fails, inspect the first `not ok` test and its assertion in the full CI log.
