## Security and transport limits
- 18 MiB streamed POST ceiling; 16 MiB canonical JSON; max 64 total devices; exact version+registry+query set; SHA-256 sorted recursive canonical JSON; timestamp issued only by server; no explicit user secrets/tokens/identifying keys; Origin fixed for browser only; duplicate ID idempotent; missing chunks fail closed.
- Site output never includes `worker/`, `tests/`, `rules/`, docs, unreleased fixture or Wrangler config. Search/normalization does not label XML registered extension as runtime-supported.
